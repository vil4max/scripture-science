# Jehovah's Witnesses: Azbyka and Dvorkin source catalog

Survey for the planned detailed JW analysis (owner request, 2026-10-01).
All URLs returned HTTP 200 on 2026-10-01. This is a catalog of where to read,
not verified evidence: each claim taken from these works still follows
`docs/SOURCES.md` (passage opened in context, short exact excerpt, access date).

Authority: **DOC** = church document; **IND** = individual author. Azbyka hosts
no synodal act that names Jehovah's Witnesses; the 1994 Bishops' Council
definition on pseudo-Christian sects does not name them.

`AZ` = `https://azbyka.ru`.
